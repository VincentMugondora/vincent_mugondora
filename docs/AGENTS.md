# Project Rules

Read this before writing or modifying code.

## What this is

The official personal website and digital brand hub for Vincent Mugondora — Software Engineer, AI Builder, Educator, and Entrepreneur.

## Stack

- Framework: Astro
- Language: TypeScript
- Styling: Tailwind CSS
- Content: Astro Content Collections / Markdown
- Deployment: Vercel or Cloudflare
- Domain: vincentmugondora.com

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run lint

Always run the build and lint checks before considering a task complete.

Conventions
Use feature/page-oriented organization.
Prefer reusable components over duplicated markup.
Use TypeScript for all application logic.
Use semantic HTML.
Follow the design system defined in ARCHITECTURE.md.
Use Space Grotesk for headings and Inter for body text.
Use JetBrains Mono for code/technical labels.
Keep components focused and composable.
Do not put unnecessary business logic in UI components.
Optimize images and avoid unnecessary JavaScript.
Rules
Do not add dependencies without asking first.
Do not change the visual identity without recording the decision in DECISIONS.md.
Do not invent portfolio achievements, statistics, testimonials, clients, awards, or experience.
Do not fabricate project results.
Do not modify generated/build files.
Do not refactor unrelated code.
Preserve accessibility and responsive behavior.
Check existing components before creating duplicates.

Known gotchas
The portfolio is a personal brand site, not a SaaS dashboard.
Avoid generic developer-template aesthetics.
Do not overuse gradients, glassmorphism, rounded cards, or animations.
The reference portfolio image defines the visual direction; Vincent's brand system defines the identity.
