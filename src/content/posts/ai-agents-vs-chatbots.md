People use "chatbot" and "AI agent" as if they mean the same thing. They don't. The difference matters — especially if you're about to invest money in building one.

I build both for clients. A chatbot is the right solution maybe 60% of the time. An AI agent is what the other 40% actually need. Choosing wrong means either overspending on something simple or underpowering something complex.

Here's how to tell them apart.

## What is a chatbot?

A chatbot is software that responds to messages. That's it.

It can be simple — a menu-driven bot on WhatsApp that says "Press 1 for pricing, Press 2 for support." Or it can be powered by AI — understanding natural language and pulling answers from a knowledge base.

But the key trait of a chatbot is this: **it responds. It doesn't act.**

You ask a question, it gives an answer. The conversation ends. It doesn't go off and do things on your behalf.

**Common examples:**

- A website chat widget that answers FAQs
- A WhatsApp bot that gives customers your business hours, pricing, or directions
- A support bot that searches your help docs and returns relevant articles
- A menu-driven bot that routes enquiries to the right department

Chatbots are reactive. Someone sends a message, the bot replies. No message, no activity.

## What is an AI agent?

An AI agent is software that completes tasks autonomously. You give it a goal, and it figures out how to achieve it — planning steps, using tools, evaluating results, and adjusting its approach.

I've written a full breakdown of [how AI agents work](/writing/ai-agents-explained-for-beginners) if you want the detailed version. The short version: an agent combines a language model (for thinking) with tools (for doing) and memory (for context).

The key difference: **an agent acts. It doesn't wait for you to ask questions — it goes and does things.**

## The key differences

### Reactivity vs autonomy

A chatbot waits for input. No message from a user, nothing happens.

An AI agent can operate independently. Give it a goal like "process all invoices from this week" and it runs without waiting for someone to type a message.

### Single-turn vs multi-step

A chatbot handles one exchange at a time. Question in, answer out.

An AI agent handles multi-step tasks. It might need to read a document, extract data, check it against a database, send an email, and update a spreadsheet — all from a single instruction.

### Fixed responses vs tool usage

A chatbot pulls from a knowledge base or generates text. Its output is always a message back to the user.

An AI agent uses tools — it can call APIs, query databases, send emails, write files, browse the web, and run code. Its output is completed work, not just words.

### Stateless vs stateful

Most chatbots treat each conversation as relatively independent. They might remember the current session, but they don't build up context over time.

AI agents maintain state across an entire task — and often across multiple tasks. They remember what they've done, what worked, and what your preferences are.

## When to use a chatbot

Chatbots are the right choice when:

- **The task is answering questions.** If customers mostly ask "What are your hours?" or "How much does X cost?" — a chatbot handles this perfectly.
- **You need 24/7 first response.** A chatbot can acknowledge enquiries, gather basic information, and tell people you'll follow up.
- **The responses are predictable.** If you can write out the 50 most common questions and their answers, a chatbot delivers them reliably.
- **Budget is limited.** Chatbots are simpler and cheaper to build and maintain.
- **Speed matters more than depth.** A chatbot responds in under a second. An agent might take 30 seconds to complete a complex task.

A well-built chatbot can handle 70-80% of routine customer enquiries without human intervention. That's enormously valuable — and you don't need an agent for it.

## When to use an AI agent

An AI agent is the right choice when:

- **The task has multiple steps.** If completing the task requires doing several things in sequence — reading, checking, sending, updating — that's agent territory.
- **Decisions need to be made.** If the correct action depends on context that varies each time, an agent can reason through it.
- **Tools need to be used.** If the task requires interacting with other systems (CRMs, email, databases, spreadsheets), an agent connects to them.
- **The work is repetitive but variable.** Same type of task, different specifics each time. An agent handles the variation.
- **You need work done, not answers given.** If the end result is a completed task rather than a message, you need an agent.

**Examples of agent work:**

- Processing incoming documents, extracting data, and entering it into your systems
- Qualifying sales leads based on criteria and sending personalised follow-ups
- Monitoring data sources and alerting you when specific conditions are met
- Researching a topic across multiple sources and producing a structured report

## Can they work together?

Yes — and this is often the best architecture.

The chatbot is the **interface**. It's what the customer talks to. It handles simple questions directly, provides a friendly conversational experience, and keeps response times fast.

The AI agent is the **backend brain**. When the chatbot encounters something complex — a request that needs multiple steps, a question that requires checking several systems, or a task that needs to be completed — it hands off to the agent.

**Example:** A customer messages your WhatsApp bot asking to reschedule their appointment.

- The **chatbot** handles the greeting, understands the request, and asks which appointment they mean.
- The **AI agent** takes over behind the scenes: checks the calendar system, finds available slots, considers the customer's preferences from past bookings, proposes options, and once confirmed, updates the calendar, sends confirmation emails, and adjusts any related reminders.

The customer experiences a smooth conversation. Behind it, the agent did six different things across three systems.

## For business owners: which do you need?

Ask yourself these questions:

**1. What's the end result you want?**

- If it's "answer customer questions faster" → chatbot
- If it's "complete a business process that currently takes staff hours" → agent

**2. Does the task require using other tools or systems?**

- If no (just responding with information) → chatbot
- If yes (needs to read databases, send emails, update records) → agent

**3. How many steps does the task involve?**

- One step (question → answer) → chatbot
- Multiple steps (read → decide → act → verify) → agent

**4. What's your budget?**

- A solid chatbot costs less to build and run. If a chatbot solves 80% of your problem, start there.
- An AI agent is an investment — but the ROI is higher for complex workflows that currently eat up human time.

**My recommendation:** Start with a chatbot for customer-facing communication. Once that's working and you can see where conversations hit a wall — where customers need something done, not just answered — that's where you introduce an agent.

## The bottom line

A chatbot answers. An AI agent does.

Both are valuable. Neither is universally better. The right choice depends on what you're trying to accomplish — not on which sounds more impressive.
